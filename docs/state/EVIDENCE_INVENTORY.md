**Reading:** ~80% of the Cognitive Trace Layer already persists. The gaps are two
split-brains (mission truth, audit), one unregistered store (workspace ledgers), one
unpersisted fragment (DecisionReports). Consolidate these and CTL is a **query**, not a build.
