# Belief Signatures — the observable traces a genuine belief must leave

> The behavioural signatures that follow *necessarily* from "belief = content-bearing,
> counterfactually-stable, evidence-sensitive disposition." A system lacking any of these
> lacks (that) belief. Each signature = the observable shadow of one ontological entity
> (ONTOLOGY_OF_BELIEF) or criterion (BELIEF_CRITERIA). Tags on necessity.

## The necessary signatures

### SIG-1 · Content-specific covariation · SUPPORTED (necessary)
The disposition tracks the **specific** state of affairs and **discriminates its negation**:
behaviour under P differs systematically from behaviour under ¬P, and not merely with a
confound. (Shadow of O1 Content / N1.) *Absent → not about P → not a belief about P.*

### SIG-2 · Systematic behavioural influence across decisions · SUPPORTED (necessary)
The belief changes action/prediction wherever the content is decision-relevant — *many*
situations, not one. (Shadow of O4 Disposition / N2.) *Absent → epiphenomenal → no belief.*

### SIG-3 · Counterfactual / off-distribution stability · SUPPORTED (necessary)
The disposition holds in **novel situations entailed by the content** that the system was not
specifically trained/told to answer — it *generalizes*. (Shadow of N3 stability + the
counterfactual rung.) *Absent → a memorized point, not a belief.* **This is the signature that
most sharply separates belief from lookup (FALSE_POSITIVES).**

### SIG-4 · Inferential integration / systematicity · SUPPORTED (necessary) (Evans' Generality Constraint)
The belief *combines* with other beliefs and fresh premises to yield **new** dispositions the
system was never given directly (believe aRb ⇒ can entertain bRa, aRc…). (Shadow of content +
disposition being *productive*.) *Absent → an isolated cached response, not an integrated belief.*

### SIG-5 · Evidence-sensitivity in the right direction · SUPPORTED (necessary for empirical belief)
On decisive relevant evidence, the disposition shifts *toward* the evidence (updating; VoE
surprise then revision). (Shadow of N4 revisability / O5 dynamics.) *Absent (sealed) → dogma/
reflex, not empirical belief.*

### SIG-6 · Direction of fit = mind-to-world · SUPPORTED (necessary; separates from desire)
On a content↔world mismatch, the state *yields to the world* rather than driving the world to
match it. *Absent (drives world instead) → a desire/goal, not a belief.*

## Signature ↔ criterion map
| Signature | Backs criterion | Separates belief from |
|---|---|---|
| SIG-1 content covariation | N1 content | reflex / noise |
| SIG-2 systematic influence | N2 disposition | epiphenomenon |
| SIG-3 off-distribution stability | N3 stability | rote memory / lookup / heuristic |
| SIG-4 inferential integration | productivity | cached answer / retrieval |
| SIG-5 evidence-sensitivity | N4 revisability | habit / frozen record |
| SIG-6 direction of fit | (constitutive) | desire / goal |

## The minimal signature set (SUPPORTED)
A state is (empirical) belief **iff** it exhibits **SIG-1 ∧ SIG-2 ∧ SIG-3 ∧ SIG-4 ∧ SIG-5 ∧
SIG-6**. SIG-5 may be relaxed for non-empirical (evaluative) belief; the rest are load-bearing.
Notably **persistence is NOT a signature** — none of SIG-1..6 requires the belief to be stored
between uses, only that the *disposition reproduce* (SIG-3), which re-derivation satisfies
(prior mission).

## Sufficiency caveat · LIKELY
The conjunction is *jointly sufficient for ascribing dispositional belief on every surviving
model.* Whether it is sufficient for "genuine" belief in a stronger (representational/
phenomenal) sense is **contested** and pushed to REDTEAM_OF_OBSERVABILITY — the signatures
certify the *functional* belief, which is the only belief the prior mission left standing.
