# Belief Axioms — the smallest surviving set

> Consistency + compression pass over the four prior belief-science missions (Definition,
> Observability, Causation, Boundaries), treated as **observations**, not documents. No new
> literature. Tags: SUPPORTED / LIKELY / SPECULATIVE / UNKNOWN / FALSIFIED / RETRACTED.

## Step 1 — the surviving core (OBJECTIVE 1; retracted/falsified removed)
Only these claims survived all prior red-teams:
- **s1** Belief is a *disposition*, not a stored object. (SUPPORTED)
- **s2** The disposition is *counterfactually stable* (reproducible across conditions), realizable
  by storage **or** re-derivation. (SUPPORTED)
- **s3** Belief has *content* — it covaries with a specific range of world-conditions. (SUPPORTED)
- **s4** Belief has *mind-to-world direction of fit* — on the input side it tracks the world; on
  the output side it disposes action. (SUPPORTED for the cut; LIKELY as exceptionless)
- **s5** Belief is *evidence-sensitive / revisable in principle* (for empirical belief). (LIKELY)
- **s6** Belief is *observable only through behaviour across counterfactual conditions*. (SUPPORTED)
- **s7** Belief-*existence* is behaviourally inferable; exact *content* is underdetermined
  (coarse individuation). (SUPPORTED)
- **s8** Belief is a *cause* iff it is *invariant under intervention* (+ mediates); the belief-
  **state** is such a difference-maker. (SUPPORTED for state; content-vs-vehicle UNKNOWN)
- **s9** Belief is scientifically warranted *exactly to the extent it changes prediction or
  intervention*. (SUPPORTED)
- **s10** Belief has *no classical essence*; it is a *cluster kind* — hard core (s4+s5),
  fuzzy periphery. (LIKELY)
- **s11** *Persistence* is neither necessary nor sufficient (carrier is a free variable). (SUPPORTED)

Explicitly excluded (FALSIFIED/RETRACTED, per prior missions): belief = persisted object;
belief has a classical essence / sharp boundary; belief individuated as a discrete object;
belief-state epiphenomenal; behaviour = belief (naive). One item is UNKNOWN, not a claim:
content-vs-vehicle efficacy.

## Step 2 — the compression (OBJECTIVES 3–4)
Every surviving claim shares one structure: a **counterfactual relation** whose grain is set by
where it holds. The pivotal observation: **"disposition" (s1), "stability" (s2), "observable via
counterfactuals" (s6), and "cause = invariance under intervention" (s8) are the same object seen
four ways — a counterfactually-invariant relation.** Content (s3) is its *input index*;
direction-of-fit (s4) is its *world→state→action asymmetry*; carrier-independence (s11) and coarse
individuation (s7) and cluster-structure (s10) are all consequences of *grain-relativity*.

Repeated compression collapses s1–s11 to **one** principle (derivations in BELIEF_THEOREMS;
each discarded concept in COMPRESSION_LOG).

## THE AXIOM (single) · LIKELY
> **A** — **Belief is a counterfactually-invariant relation between a system's world-tracking
> states and its actions — from the world-conditions it covaries with, to the actions it disposes
> — existing exactly where, and at the grain at which, that invariance is exploitable for
> prediction and intervention.**

Read the clauses:
- *counterfactually-invariant* → s1 disposition, s2 stability, s6 counterfactual-observability,
  s8 intervention-invariance (cause).
- *between world-tracking states and actions* → s3 content (input index), s4 direction of fit
  (world→state input, state→action output).
- *exists exactly where … exploitable for prediction and intervention* → s9 warrant, s7 coarse
  individuation, s10 cluster core/periphery.
- *at the grain / any substrate* → s11 carrier-independence.

## Why it is ONE axiom, not an essence · SUPPORTED (this resolves the s10 worry)
The axiom is **relational and grain-indexed**, not a shared intrinsic property. "At the grain
where the invariance holds" *builds in* the fuzzy periphery: **strong** invariance = the hard
core; **weak/partial** invariance = the soft edge (the liminal cases). So a *first principle* is
possible **without** a *classical essence* — the principle *generates* a cluster kind. This is
precisely why OBJECTIVE 5's answer is "yes, a first principle" while Mission IV's "no essence"
stands. (A first principle ≠ an essence when it is a principle of grade.)

## The one thing the axiom does NOT fix · UNKNOWN
Whether the invariance is carried by the state's **content** (semantics) or only its **vehicle**
(Mission III's open question). The axiom quantifies over the belief-**variable**; it is silent on
*which property of the state* carries the invariance. This UNKNOWN is quarantined, not resolved
(see REDTEAM_OF_UNIFICATION).
