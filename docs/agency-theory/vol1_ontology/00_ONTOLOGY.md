## Q1 · What is an agent?

Every tradition names the same core from a different side:

- **Cybernetics** (Rosenblueth–Wiener–Bigelow; Ashby): a system with a *goal* and
  *negative feedback* that acts to reduce the error between goal and observed state.
  Purpose = error-correction. SUPPORTED as the minimal mechanism.
- **Decision theory** (von Neumann–Morgenstern; Savage): a system with *preferences*
  that *chooses* actions to maximize expected utility. SUPPORTED as the normative
  core.
- **AI** (Russell & Norvig): a system that *perceives* an environment (sensors) and
  *acts* on it (actuators); *rational* iff it acts to maximize an expected performance
  measure. SUPPORTED as the operational schema.
- **Philosophy of action** (Anscombe; Davidson): an agent *does things intentionally*
  — behaviour answerable to "why?" with a *reason*; action = behaviour caused-by and
  rationalized-by the agent's reasons. SUPPORTED for full/deliberative agency.
- **Intentional stance** (Dennett): a system is an agent iff its behaviour is
  predictable by ascribing beliefs, desires, and rationality. CONTESTED — makes
  agency a *stance*, not an intrinsic fact (the realism/instrumentalism fault line).

**Recovered core (SUPPORTED):** an agent is *a system that selects actions on an
environment in a way that depends on an END it holds* — a locus of goal-directed
intervention. It is not defined by what it is made of (multiple realizability) but by
this functional relation: end → (via observation) → action → outcome → end.

**The structural definition (the sharpest recovery, LIKELY):** an agent is precisely
*a system that couples both directions of fit in a feedback loop* — it uses
**mind→world** representation (perception, to read how the world is) to drive
**world→mind** attitudes (goal/policy, to make the world how it should be). Belief
alone is one direction (Part I). **Agency is the closed loop of both directions.** A
pure perceiver (all mind→world, no action) is not an agent; a pure actuator (all
world→mind, no perception) is a ballistic mechanism. Agency lives exactly at their
coupling. This is why the Observation node is shared by the Knowing and Acting loops
(the hinge doc): it is the mind→world half *inside* the agent.

## Q3 / D1 · The minimal ontology (thirteen entities)

Defined minimally, each tagged by direction of fit (Q4) — **W→M** (world-to-mind: an
attitude aiming to change the world), **M→W** (mind-to-world: a representation fitting
the world), **—** (a world-fact, neither).

| Entity | Minimal definition | Fit |
|---|---|---|
| **Value** | the standard by which outcomes are ranked; what *matters* (more fundamental than any goal) | **W→M** |
| **Preference** | an ordering ≽ over outcomes/options (ordinal) | **W→M** |
| **Utility** | a numerical representation of preference *iff* the VNM axioms hold (cardinal encoding) | **W→M** |
| **Goal** | a target state the agent aims to bring about (a value made concrete as a state) | **W→M** |
| **Intention** | a *settled, conduct-controlling* aim toward an action/end (Bratman) — the executable, committed form of a goal | **W→M** |
| **Commitment** | a stabilized intention resistant to reconsideration — temporal coherence of the will (Bratman) | **W→M** |
| **Policy** | a mapping from observed states to actions, π: Obs → Action — the *standing disposition to act* | **W→M** |
| **Action** | an intervention on the environment, caused-by and rationalized-by the agent's reasons (Davidson); do(a) (Pearl) | **W→M** |
| **Observation** | the agent's (possibly partial) access to the environment state — sensors | **M→W** |
| **Outcome** | the resulting environment state after action (possibly stochastic) | — |
| **Environment** | the external state space + its transition dynamics | — |
| **Capability** | the set of actions the agent *can* perform (effectors) | — |
| **Constraint** | limits on action (physical, resource, normative) | — |

## Q4 · Direction of fit — the decisive split

- **World-to-mind (the agency direction):** Value, Preference, Utility, Goal,
  Intention, Commitment, Policy, Action. All are about *making the world match* — the
  Anscombe/Searle direction of *desire and intention*. This bloc is what Part I did
  **not** contain; it is the new domain. SUPPORTED.
- **Mind-to-world (borrowed from Part I):** Observation (and the agent's internal
  world-model) — these *fit the world*, they represent it. They are the sensor the
  W→M bloc steers by. SUPPORTED.
- **Neither (world-facts):** Outcome, Environment, Capability, Constraint — the
  terrain, not attitudes. SUPPORTED.

**The recovered thesis (LIKELY, and the volume's spine):** *agency is the coupling of
the two directions of fit through Action and Observation.* Value/Goal/Policy (W→M) set
what to make true; Observation (M→W) reports what is true; Action closes W→M onto the
world; Outcome re-enters Observation (M→W). Remove the M→W half → a blind actuator
(ballistic); remove the W→M half → a pure knower (Part I). **An agent is neither half
alone — it is the loop.** This locates agency exactly, and it explains why the Theory
of Knowing had to *stop* at the belief pole: it had only one direction, and agency
needs both.

## Falsifiers
Q1's core is refuted by a genuine agent whose action does **not** depend on any end
(action fully goal-independent — then it is mechanism, not agency). The
both-directions thesis (Q4) is refuted by a genuine agent that is *purely* W→M with
no observation of any kind (a truly open-loop system we would still call an agent
in the full sense) — the ballistic/reflex limiting case tests this and is treated as
degenerate, not central, in Volume-I §counterexamples. The direction-of-fit
assignment of each entity is refuted by showing an entity in the table fits the
world rather than aims to change it (or vice versa).
