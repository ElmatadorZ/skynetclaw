## Necessary conditions — what makes a movement an *execution*?

Removal-tests, distinguishing execution from movement / spasm / reflex / accident / lucky
success / control.

| Candidate | Necessary? | Test |
|---|---|---|
| **A commitment** (a settled intention/plan to realize) | **YES (SUPPORTED)** | no commitment → mere movement or reflex; there is nothing being *carried out*. Inherited from Vol III/IV. |
| **An intervention** (a real causal change to the world) | **YES (SUPPORTED)** | no world-change → nothing was *done*; at most an attempt that failed (failed execution, file 03). Inherited from Part I causation. |
| **Guidance / control** (the movement is steered by the intention, counterfactually goal-sensitive) | **YES (SUPPORTED — the finding)** | *the deviant chain*: commitment + causation + outcome present, guidance ABSENT → **not an execution**. Guidance is the differentia. Argued below. |
| **Irreversibility** (an irreversible act-event is incurred) | **YES (SUPPORTED)** | every execution *spends the now* — the act-token enters the fixed past. The minimal necessary irreversibility (below). Inherited-and-incurred from Vol IV. |
| **Success / intended outcome** | **NO** | a *failed* or *wrong* execution is still an execution (file 03). Success is the target, not the act — exactly Vol III's outcome≠quality. |
| **Consciousness / deliberateness in the moment** | **NO** | habitual/automatic execution (Vol IV compiled) is guided without moment-to-moment deliberation. |

**Recovered necessary core (SUPPORTED):** `{ commitment, intervention, guidance,
irreversible act-event }`. Three are inherited (commitment ← Vol III, intervention ← Part
I causation, irreversibility ← Vol IV); **the volume's own contribution is Guidance.**

## The deviant-chain crux — why Guidance is the new primitive

**The test the user themselves posed:** `Execution = Committed Intervention that changes
the world`. Run it against the climber:
- committed intention to loosen the grip ✓
- an intervention (the grip loosens, a real causal change) ✓
- the world changes / the man falls (intended outcome) ✓
- **and yet it is not an execution** — it was a nervous spasm the wish *triggered*, not a
  doing the intention *guided*.

So `Committed Intervention that changes the world` is **FALSIFIED as sufficient** — it is
satisfied by the deviant chain, which is not an execution. The missing element is
**Guidance**: in genuine execution the intention *steers the unfolding movement*, so that
(counterfactually) a deviation would be *detected and corrected* toward the intended. The
climber's loosening had no such steering — had his hand begun to *tighten*, nothing in the
"intention" would have corrected it toward loosening; it was open-loop nerves. The
operational mark of guidance:

> **Guidance test (SUPPORTED as the criterion):** *would a deviation from the intended
> have been corrected?* Yes → guided (execution). No → merely triggered (deviant / spasm /
> accident). Guidance is the intention's *ongoing counterfactual control* over the movement,
> not its *initial causal push*.

**Guidance is a genuinely new primitive** (not reducible to Vol I–IV):
1. **It is not Commitment** — the climber was committed and still did not execute.
2. **It is not Intervention** — the intervention occurred; guidance is about *how* it was
   produced (steered vs triggered).
3. **It is not Vol IV's Dependency or Irreversibility** — those structure the *plan*;
   guidance operates *within a single act*, moment-to-moment.
4. **It owns a failure mode nothing else can produce** (file 03): the *deviant execution*
   (right outcome, no guidance) and *execution drift* (guidance diverging mid-act). A
   primitive is real iff it owns failures the others cannot — Guidance passes.

**What Guidance IS, structurally (LIKELY, and it deepens the stack):** guidance is
**Observation running inside the act** — the world→mind sensor feeding correction into the
mind→world movement *continuously*, at the finest grain (motor control). So Execution is
where the two directions of fit **fuse in real time**, tighter than anywhere else in the
stack: Decision *combined* belief and value between acts (Vol III); Execution *couples*
sensing and doing *within* the act. This is why the deviant-chain problem lives here and
nowhere else — it is the question of whether the sense→act coupling was actually closed.

## The honest OPEN residue — "the right way" is unsolved
Guidance is SUPPORTED as *necessary* and as the *right kind* of answer. But the *complete*
specification — a condition on guidance that provably excludes **every** deviant chain — is
**UNKNOWN**. Davidson posed the problem and did not solve it; successors (Bishop, Peacocke,
"sensitivity"/"differential explanation" accounts) refine but none is agreed to close it,
because deviant chains can be constructed *inside* the guidance loop too (a sensor that
"corrects" via a second deviant path). **The volume claims Guidance is the missing
primitive; it does not claim to have solved the deviant-chain problem.** Tagging: *Guidance
is necessary* — SUPPORTED; *this guidance-condition rules out all deviance* — OPEN. Claiming
otherwise would be exactly the overclaim C1 forbids.

## The minimal primitive of execution (recovered)

> **Execution = Commitment ⊕ Intervention ⊕ Guidance ⊕ Irreversibility(act-event).**
> The user's `Committed Intervention that changes the world` is **Commitment + Intervention
> + world-change** — correct in three parts, **missing Guidance**, the part the deviant
> chain proves indispensable. Add Guidance and the formula holds (SUPPORTED); its
> *complete* anti-deviance form remains OPEN.

Note the exact parallel to Vol IV's result: there, the mission's formula was missing one
primitive (Irreversibility) that owned the characteristic failures; here, it is missing one
(Guidance) that owns the characteristic failure (deviance). Two volumes, same shape: the
proposed formula is *nearly* right and recovery finds the one missing, failure-owning term.

## Irreversibility here — the act-event vs the state (refining the user's theorem)
The user proposed `No Irreversible Effect → No Execution`. Refined with a distinction:
- The **act-event** is *always* irreversible — the doing *happened*, the now is spent, the
  opportunity is gone (even a "reversible" switch-flip irreversibly *occurred*). This is the
  minimal necessary irreversibility, and it is *time-as-consumed* (Vol IV's master resource).
- The **state-effect** is *often but not always* irreversible (some effects can be undone).

So `No Irreversible Effect → No Execution` is **TRUE reading "effect" as the irreversible
act-event** (the execution's occurrence enters the fixed past), and **too strong reading it
as a permanent world-state change** (reversible-state executions exist). The irreducible
irreversibility of execution is the **spending of agency's now**, not necessarily a
permanent scar on the world (file 04, PT).

## The execution graph

```
     PLAN  (Vol IV: Commitment ⊕ Dependency ⊕ Irreversibility)
       │  (a) selects the next committed intervention
       ▼
   INTENTION-IN-ACTION  ── the commitment now driving THIS movement (Searle)
       │  (b) NECESSARY — guidance couples to it
       ▼
   ╔══════════════╗        ┌───────────── OBSERVATION (in-loop) ─────────────┐
   ║  GUIDANCE    ║ ◀──────┤ world→mind, at motor grain: detect deviation     │
   ║  (control)   ║        └──────────────────────────────────────────────────┘
       │  (c) NECESSARY — steers the movement (anti-deviance)
       ▼
    MOVEMENT ──(d)──▶ INTERVENTION ──(e)──▶ WORLD CHANGE  ── irreversible act-event incurred
                                                 │
                                                 ▼
                                          OUTCOME  +  SIDE EFFECTS (world's excess connectivity)
                                                 │
                                                 ▼
                                          OBSERVATION (post-act) → Vol VI Learning
```

**Edge verdicts:**
- **(b) intention-in-action, (c) guidance — NECESSARY (the identity of execution).** Remove
  guidance and (d)–(e) still occur, but as *movement→intervention→change* with no execution
  (the deviant chain / landslide). These two edges are what make it an execution. SUPPORTED.
- **(a) plan→intention-in-action — NECESSARY** (else uncommitted movement). SUPPORTED.
- **(d) movement→intervention, (e) intervention→world-change — the causal realization;
  NECESSARY for the execution to *succeed*, but a failed execution (movement, no
  world-change) is still an execution attempt** — so efficacy grades success, not
  execution-hood. LIKELY.
- **In-loop Observation → Guidance — NECESSARY for closed-loop (guided) execution;** its
  absence is precisely open-loop triggering = the deviant/ballistic limit. This is the
  finest-grain appearance of the shared Observation node — the hinge's sensor, now *inside*
  the act. SUPPORTED.

## Falsifiers
The Guidance-as-primitive claim fails if (i) the deviant chain is shown to *be* an execution
after all (guidance not needed), or (ii) deviance is shown eliminable by Commitment +
Intervention alone (guidance reduces). The act-event-irreversibility refinement fails if a
genuine execution is exhibited that incurs *no* irreversible occurrence (leaves no trace in
the fixed past — not the now spent, not a resource used). The in-loop-Observation claim
fails if fully open-loop ballistic action with zero feedback is a *paradigm* execution
rather than its degenerate limit.
