# Agency — Volume II · 02 — Counterexamples & Boundary Cases

> Pure philosophy. Deliverables 5 (boundary cases) + 6 (counterexamples). Test the
> value ontology against hard bearers: what has value, of which kind, and where the
> categories blur. As in Vol I, the result is a **spectrum**, not a predicate.

---

## The cases, graded

Each case tested for: does it bear **terminal** value, **instrumental** value, or
neither? Is its value **held** (a standard the system tracks) or merely **ascribed**
(by an observer)? Is it a **value** or a **reward** (a sensor)?

| Bearer | Terminal? | Instrumental? | Held or ascribed? | Verdict |
|---|---|---|---|---|
| **Pleasure / pain** | ✔ (paradigm terminal) | — | held (felt) | clearest terminal value — yet see hedonism boundary |
| **Money** | ✖ | ✔ (pure) | held instrumentally | the pure-instrumental limit; terminal only by pathology (miser) |
| **A paperclip** (to a paperclip-maximizer) | ✔ *by stipulation* | — | held | terminal value can be *arbitrary* — the key boundary |
| **A rock** (no agent) | ✖ | ✖ | none | no value without a valuer? (Q9 crux) |
| **An addict's craving** | ✖ (disendorsed) | ✖ | *reward without value* | reward≠value made vivid |
| **An evolved drive** (sweetness) | ~ (was proxy) | ~ (obsolete means) | held, unendorsed | value came apart from its origin |
| **A reflectively endorsed ideal** (justice) | ✔ | — | held + endorsed | terminal + second-order (Frankfurt) |

## The recovered result: value is a spectrum on two axes

Like *agent* (Vol I) and *belief*/*warrant* (Part I), **value is degreed**, not a
classical predicate — and it stratifies on **two independent axes**:

- **Axis A — terminal ↔ instrumental** (Q5): how far from the grounding floor. Money is
  the pure-instrumental pole; pleasure/justice the terminal pole; most values sit
  between (health: terminal for some, instrumental for others).
- **Axis B — held ↔ ascribed** (the valuer question): whether the value is a standard a
  system *tracks* (held) or a stance an *observer* projects (ascribed). A rock's
  "value" is wholly ascribed; a human's endorsed ideal is fully held; an evolved drive
  is *held but unendorsed* (the system tracks it without ratifying it).

These axes are orthogonal: a value can be terminal-but-unendorsed (an addict's craving,
if we granted it terminality — which we don't, see below) or instrumental-and-endorsed
(money, wisely held). Two axes, not one line. LIKELY.

## Boundary cases dissected (D5)

- **The paperclip-maximizer — arbitrariness of terminal value.** By V2 a value
  structure needs *a* terminal floor, but the ontology says **nothing about what the
  floor contains** (that is ethics, Vol II·00 scope note). So "maximize paperclips" is
  a *formally valid* terminal value — grounded, orderable, derivable. This is the
  sharpest boundary: **the ontology of value is silent on the content of value**, and
  that silence is exactly why alignment is hard (Bostrom's orthogonality thesis:
  intelligence and terminal goals vary independently). The volume *owns* this: it
  recovers the *form* of value and declares the *content* out of scope — the same
  is/ought fence the hinge doc drew. SUPPORTED as a boundary; the discomfort is real
  and correctly located, not resolved.
- **The addict's craving — reward without value.** A craving delivers a strong
  *reward* signal yet the agent *disendorses* it ("I don't want to want this",
  Frankfurt). This is **reward with no backing value** — the M→W sensor firing while the
  W→M standard says "no." It is the cleanest real-world proof of Vol II·00's spine
  (reward ≠ value) and the human face of wireheading (F4): the signal captured, the
  value absent. The ontology places it precisely — a live Reward node with an empty (or
  contrary) Terminal-value node. SUPPORTED.
- **The evolved drive — value divorced from origin.** We value sweetness; evolution
  installed it as a *proxy* for caloric fitness; in a sugar-rich world the proxy has
  come apart from what it once tracked. This shows two things: (i) value has a *causal*
  origin (evolution, Q9) — answerable; (ii) that origin does **not** ground the value's
  *present authority* — we can and do judge the drive obsolete. **Causal-origin ≠
  normative-authority** (the Q9 distinction) is *visible in a single case*. SUPPORTED,
  and it pre-empts the naturalistic fallacy: "we evolved to value X" ⇏ "X is valuable."
- **The rock / the valuer question — can value exist unheld?** Does a rock (or a
  lifeless universe) contain value with no agent to hold it? **Realists** (Moore,
  Parfit): yes — value is mind-independent, agents *discover* it. **Constructivists /
  subjectivists**: no — value is *conferred* by valuers; no valuer, no value. This is
  the metaphysical crux behind Q9 and it is CONTESTED, unresolved. The ontology can
  proceed either way (it needs only that *held* value has the recovered structure); it
  flags the rock as the point where axiology meets metaphysics and declines to decree.

## What the counterexamples prove about the ontology
1. **No sharp bearer-line.** Every case sits on the terminal↔instrumental and
   held↔ascribed axes; none forces a binary "is/isn't a value." Value is degreed.
   SUPPORTED.
2. **Content is out of scope — and that is the whole point.** The paperclip case shows
   the ontology is deliberately *content-neutral* (orthogonality). This is not a gap;
   it is the is/ought fence honoured. Trying to smuggle content in would be the exact
   error Part I forbade (deriving ought from is). SUPPORTED.
3. **Reward≠value is not a theory but a *phenomenon*.** The addict and the evolved
   drive are cases you can *point at*. The distinction the whole volume rests on is
   observable, not stipulated. SUPPORTED — the strongest evidence in the volume.

## Falsifiers
The spectrum is refuted by a principled, exceptionless line sorting every bearer into
value/non-value with no residue. The two-axis claim fails if terminal↔instrumental and
held↔ascribed provably co-vary. The reward≠value phenomenon fails if the addict/craving
cases can be fully redescribed with *no* gap between signal and endorsed standard
(would collapse the spine — but the first-person "I don't want to want this" resists
the redescription).
