## The theorems

### VT1 · The Value-Decision Theorem — *No Value → No Decision* (Q10)
**Statement.** A system with no value — no ranking ground over outcomes — does not
*decide*; it at most *picks* (samples arbitrarily). Decision is selection *for a
reason*, and value is the reason.

**Support: SUPPORTED for discriminating value; the strong "represented value" form
CONTESTED — the same double structure as Vol I's T1.** Precisely:
- *Weak (order) reading:* no ranking at all → every option is on a par → "choice"
  collapses to a coin flip. There is selection but no *decision*. **SUPPORTED** — it
  follows from V1 (value is a ranking): remove the ranking, remove the criterion that
  makes one option choiceworthy over another.
- *Strong (represented) reading:* no *held, represented* value → no *genuine* deciding
  (only as-if optimization by an observer's lights). **CONTESTED** — the thermostat
  "decides" to switch by an embodied setpoint it does not represent (Vol I·02); realist
  vs deflationist, unresolved.

**Verdict on "จริงไหม":** **Yes, as stated for discriminating value.** A decision needs
a *non-flat, at least locally discriminating* value; with a wholly flat value every
option is equivalent and only a draw remains (Buridan's ass). It is not trivially true:
it has the content that **the machinery of decision is empty without a criterion, and
the criterion is not itself produced by the machinery** (VT3 below). **Falsifier:**
exhibit a genuine decision (not a random pick, not a tie-break) made with a provably
flat value over the options.

### VT2 · The Fourth "No-X → No-Y" (the stack is now four-fold self-similar)
**Statement.** VT1 completes a family of four constitutive theorems, one per primitive
of the two stacks:

| Stack | Primitive | Licence | Theorem |
|---|---|---|---|
| Knowing | Belief | Warrant | **No warrant → no knowledge** (C1) |
| Knowing (forward) | Question | — | **No question → no inquired knowledge** (NQ1) |
| Acting | Goal | — | **No goal → no agency** (T1) |
| Acting | **Value** | Justification | **No value → no decision** (VT1) |

Every member has the identical three-part shape: **(a)** a strong analytic core for the
active/represented kind, **(b)** a contested deflationary perimeter for the
as-if/immediate kind, **(c)** an *open foundation* (origin of the warrant / question /
goal / value). **Support: LIKELY** (structural observation across four theories).
**Significance:** four independent recoveries landing the *same* theorem-shape is strong
evidence that direction-of-fit + the primitive/licence/output structure is the real
skeleton of the whole system, not an imposed template. **Falsifier:** show VT1's shape
genuinely differs (no open foundation, or no contested perimeter).

### VT3 · The Value-Determinacy Theorem
**Statement.** *Given* a terminal value floor and a causal/world model, the **entire
rest of the value structure is determined** — instrumental value, derived goals, and
(under VNM) utility are all *computed* (V3). Value theory is therefore **determinate
below the terminal floor and indeterminate exactly at it.** **Support: LIKELY.**
**Consequence:** the *only* open degree of freedom in the whole value ontology is the
*content of the terminal floor* — everything else is entailment. This localizes the
entire alignment problem to one node: **set the terminal floor correctly and (given
true causal knowledge) all else follows; set it wrong and flawless machinery amplifies
the error (VF4).** **Falsifier:** exhibit two agents with identical terminal floors and
world models but rationally different instrumental values.

### VT4 · The Orthogonality Corollary (Bostrom, recovered)
**Statement.** The *form* of value (V1–V4) constrains *how* value is structured but
says **nothing about its content**; therefore terminal value and capability
(intelligence) vary independently — any level of decision competence is compatible with
any terminal floor (paperclips included). **Support: SUPPORTED** as following from the
content-neutrality of the ontology (Vol II·02). **Consequence:** competence does not
converge on benign values; the is/ought fence (hinge doc) has teeth — *no amount of
knowing-side progress supplies the terminal floor.* This is the sharpest practical
result of the volume and the reason value needed its own book. **Falsifier:** show some
terminal contents are *unreachable* by sufficiently capable agents (a value–capability
coupling) — would bound the danger structurally.

### VT5 · Reward is a fallible sensor of value (recovered as a theorem)
**Statement.** Reward is M→W (a measurement of value-achievement); like every sensor it
can be biased (VF1 hacking) or captured (VF2 wireheading); therefore *identifying reward
with value removes the only ground on which reward could be wrong.* **Support:
SUPPORTED.** **Consequence:** the correct discipline is Russell's — reward as evidence
updating an uncertain value (C1 on the value channel). **Falsifier:** a reward channel
that provably *cannot* misrepresent value even in principle.

## Q9 · Can value emerge?

The origin-of-ends question (Vol I open-problem 1) sharpened to its exact core.
**Separate two questions that are constantly conflated** — this separation is the
deliverable:

- **(i) Causal origin — where does value come from?** ANSWERABLE. Candidates:
  *evolutionary* (values as evolved fitness-proxies — pain/pleasure/hunger; the
  sweetness case, Vol II·02); *constructivist* (Korsgaard: value conferred by the
  reflective structure of rational agency — the agent's endorsement is the source);
  *learned* (derived value emerges deductively from a terminal floor + world model,
  VT3). Derived value *demonstrably* emerges (VT3). **Terminal** value has *causal*
  origin stories (evolution, construction) that are live and partly empirical.
- **(ii) Normative authority — what makes an emerged value *binding*?** OPEN. That we
  *do* value X (however it arose) does not show X is *to be* valued — Hume's gap, and
  the sweetness case proves the origin does *not* transfer authority (we judge the
  evolved drive obsolete). Realists (Moore, Parfit): terminal value is *discovered*, not
  emergent — authority is mind-independent. Constructivists: authority *is* conferred by
  endorsement. Naturalists: authority is a further myth. Unresolved.

**Recovered answer (SUPPORTED as the distinction; the metaphysics OPEN):** *derived*
value emerges (deductively); *terminal* value has emergent **causal** origins but its
**normative authority does not emerge from those origins** — the authority-question is
the rootless-root residue, and it is genuinely open. **"Can value emerge?" = yes
causally, unknown normatively.** Keeping the two apart dissolves most of the confusion;
what remains is a real open problem, not a muddle.

## Q9-adjacent / D9 · Open problems
1. **The normative authority of terminal value** (the rootless root's residue) — VT3
   localizes *all* openness here. The single deepest open node of Part II. OPEN.
2. **Realism vs constructivism vs subjectivism about value** (the rock / valuer
   question, Vol II·02) — bears on whether value can exist unheld and on (1). OPEN.
3. **Incommensurability and the limits of utility** (Q8) — is genuine incommensurability
   real, or always resolvable by a hidden common scale? Bounds Vol III. OPEN.
4. **The reward–value identification problem** — can an agent be *constructed* to hold
   value distinct from reward robustly (defeating wireheading in principle)? The
   alignment problem in value-ontology form. OPEN (shared with Vol I·op5).
5. **Content of the terminal floor for artificial agents** — VT4 says form ⇏ content;
   VT3 says everything rides on the floor; so *which* floor, and *who sets it*, for a
   derived agent whose floor is filled from outside? Ethics proper — flagged as the
   boundary where this volume stops. OPEN (and out of scope by design).
6. **Value change / dynamic values** — the volume treats value as (mostly) static; real
   agents' terminal values shift (development, reflection, corruption). A theory of
   *value dynamics* is unaddressed here — arguably a later volume. OPEN.

## Settled vs open (honest ledger)
- **Settled (SUPPORTED):** V1–V2 (grounded ranking) + V4 (representations conditional);
  reward≠value and reward-as-fallible-sensor (VT5); orthogonality (VT4); the value graph
  and its plug-ins to Part I; value failures as root causes of agency failures.
- **Settled (LIKELY):** value-determinacy below the floor (VT3); the four-fold
  self-similarity (VT2); value-first over preference-first (Q4); two-axis value spectrum.
- **Open:** the normative authority of terminal value (1) — and everything downstream of
  it (2, 4, 5). Incommensurability's reality (3). Value dynamics (6).

The pattern holds a fourth time: **determinate in the middle, open at the foundation.**
Value's foundation-hole is the *authority of the terminal floor*, and VT3 proves it is
the *only* hole — the rest is entailment. The stack is now open at four corresponding
bottoms (ground / first question / first goal / terminal value's authority), and Vol II's
contribution is to show they are **one hole seen four ways**: the point where a system's
commitments must come from outside the system.
