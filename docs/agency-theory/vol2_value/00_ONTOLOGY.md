## Q1 · What is value?

Every tradition points at the same thing from a different side:

- **Axiology / Moore.** Value (the good) is *that in virtue of which a state is worth
  bringing about*. Moore's open-question argument: for any natural property N, "but is
  N good?" stays open — so *good* is not identical to any natural property; it is a
  distinct (for Moore, non-natural) value-property. SUPPORTED as a *non-identity*
  result; Moore's non-naturalism itself CONTESTED.
- **Fitting-attitude / buck-passing (Scanlon).** To be valuable = to have properties
  that provide *reasons* to hold pro-attitudes toward it. Value passes the buck to
  reasons. LIKELY — reduces value to normative reasons rather than a sui-generis
  property.
- **Economics / revealed preference (Samuelson).** Value just *is* what is chosen;
  there is nothing behind consistent choice. Deflationary. CONTESTED (Q4).
- **Decision theory.** Value is whatever the utility function encodes — the ranking
  that rationalizes choice. Operational, but presupposes the ranking exists (Q3, Q8).

**Recovered core (SUPPORTED):** *value is the ordering-ground of pursuit* — the
standard, prior to any particular goal, in virtue of which states of the world are
ranked as more or less worth bringing about. It is *what a preference is a preference
for the sake of*, and *what a goal is a goal because of*. Direction of fit: **world→mind**
(it says how the world *should* be).

**The load-bearing thesis (SUPPORTED, and the spine of the volume):** value is *not
identical* to desire, to choice, or to reward — it is **the target all three attempt to
track, and each can diverge from.** This is what makes Vol I's failure modes
*describable as failures*: reward hacking (F3), wireheading (F4), and akrasia (F5) are
exactly *divergences of a tracker from value*. If value were *defined* as "what is
rewarded / chosen / desired," none of those could be an error — the sentence "the
reward was wrong" would be incoherent. That the sentence *is* coherent is the empirical
proof that value is ontologically distinct from its trackers. This single distinction
is what Vol I's red team (Attack 5) found load-bearing, now made the axiom of Vol II.

## Q2 · Goal vs Value

| | Value | Goal |
|---|---|---|
| kind | a *standard / ordering* (gradient over all states) | a *target state* (a point/region in state space) |
| abstraction | criterion — "what matters" | instantiation — "bring *this* about" |
| persistence | standing (a disposition to rank) | adopted and dropped |
| multiplicity | one value → many goals; one goal → many values | — |
| dependence | root | downstream: chosen *because* it scores high on value |

**Recovered relation (SUPPORTED):** `value : goal :: objective-function : argmax`. The
goal is (roughly) a high-value reachable state; value is the function that makes it
high. A goal with no value behind it is *arbitrary* (a target for no reason); a value
with no goal is *inert* until a reachable state instantiates it. Vol I's edge
`Value → Goal` is this: goals are *selected by* value over the reachable set.

## Q3 · Utility vs Value

**Recovered (SUPPORTED):** utility is a *numerical representation* of preference that
**exists only if the VNM/Savage axioms hold** (completeness, transitivity, continuity,
independence). Utility is a *cardinal encoding*; value is the *encoded*.

- **Utility is a representation, value is the represented.** Where the axioms hold,
  utility faithfully encodes value-via-preference. Where they fail — value *incomplete*
  or *incommensurable* (Q8) — **no utility function represents value faithfully**; utility
  *over-commits* value to a total order it may not have. So `representable-value ⊊ value`.
- This is the exact seam of **reward hacking** (Vol I F3): optimizing the utility proxy
  while value diverges (Goodhart). Utility is safe to maximize *only* to the extent it
  faithfully represents value — and the axioms are the fidelity condition.

Utility is not a deeper thing than value; it is a *lossy compression* of value into the
reals, exact only under the VNM axioms.

## Q4 · Preference vs Value

**The contested heart of the volume.** Preference = a binary ordering ≽ over options,
possibly revealed by choice. Two irreconcilable positions:

- **(a) Preference-first (Humean / economic).** Value *just is* (coherent) preference;
  nothing lies behind it. The only defect a preference can have is *incoherence*
  (intransitivity, incompleteness). Hume: reason is the slave of the passions; there is
  no rational criticism of an end, only of consistency. DEFLATIONARY.
- **(b) Value-first (realist / fitting-attitude).** Preferences are *responses to*
  value and can *mis-track* it — a preference can be *wrong* (preferring the worse),
  not merely inconsistent. The standard is prior to and judges the preference.

**Recovered test to tell them apart (SUPPORTED as a test; the verdict CONTESTED):**
*can a coherent preference still be mistaken?* Two data points favor value-first:
1. **Second-order preferences (Frankfurt).** We prefer *to have different preferences*
   ("I wish I wanted better things"). Evaluating one's own preferences requires a
   standard *other than* those preferences — so the standard ≠ the preferences.
2. **Akrasia (Vol I F5).** Judging A best yet preferring-in-action B is a *gap*, which
   presupposes a "best" the action-preference failed to meet.

These do not *refute* preference-first (it can re-describe both as higher-order
preferences), but they show value-first is *not eliminable*: the appearance of a
standard above preference is robust. **Verdict: value ≠ preference is LIKELY; the
deflationary reduction survives only by treating all evaluation as more preference —
which drains "preference" of content.** The volume proceeds value-first (it needs a
standard trackers can fail against) while flagging the alternative as live.

## Q5 · Intrinsic vs Instrumental value

- **Intrinsic / terminal / final value:** valuable *for its own sake*, as an end.
- **Instrumental value:** valuable *as a means* to something else.

**The regress argument (Aristotle, SUPPORTED).** Instrumental value is always
*value-because-it-leads-to* X. If every value were instrumental, the "because-it-leads-to"
chain would regress infinitely and *nothing* would be valuable (each link borrows its
value from the next, and an infinite borrowing chain never repays). Therefore **there
must be at least one terminal (non-instrumental) value**, or the value structure is
ungrounded. This is the axiological form of the warrant-regress and the exact content
of Vol I's origin-of-ends: the rootless root is specifically the *terminal* value.

**Refinement (Korsgaard, LIKELY).** *Intrinsic* (value residing in the object's
non-relational properties) and *final* (valued as an end, not a means) are **different
axes** — a thing can be finally valued without intrinsic value (e.g. a gift valued as
an end but *because* of who gave it, a relational property). The regress needs
*terminal/final* value, not necessarily *intrinsic* value. Keeping these apart matters
for Q9 (can value emerge): constructivism can grant *final* value without *intrinsic*
value.

**The bridge to the Knowing stack (SUPPORTED, important).** Instrumental value is
**derived** — it is *computed* from terminal value + a causal/world model (what leads to
what). To know an instrumental value you must know what *causes* what. So **instrumental
value is exactly where Part I feeds Part II**: the interventionist causation recovered
on the Knowing side (Pearl, hinge doc) is the machinery that *derives* instrumental
value from terminal value. Terminal value is the world→mind primitive Part I cannot
supply (Hume); instrumental value is the *joint* where the mind→world causal knowledge
does the derivation. The two halves meet here as well as at Observation.

## Direction of fit — the value ontology tagged

| Entity | Fit | Note |
|---|---|---|
| **Terminal value** | **W→M** | the rootless root; says how the world should ultimately be |
| **Instrumental value** | **W→M** (derived) | terminal value × causal model |
| **Goal** | **W→M** | a reachable state selected by value |
| **Preference** ≽ | **W→M** | ordering of options by value |
| **Utility** | **W→M** (representation) | cardinal encoding of preference, iff VNM |
| **Reward** | **M→W** | the *sensor/estimate* of value-achievement — a measurement, hence **fallible/gameable** (Q7) |

**A recovered structural claim (LIKELY):** *reward is the observation-node of the value
axis.* Just as Observation (M→W) is the fallible sensor of the *world*, **Reward (M→W)
is the fallible sensor of *value-achievement*.** `reward : value :: observation : world`.
This immediately explains reward hacking and wireheading (Q7): they are *sensor
corruption* of the value channel, the exact analog of perceptual failure (Vol I F7) on
the knowing channel. It also predicts reward should be treated as *evidence about* value
under uncertainty, never as value itself (Russell) — the same discipline C1 imposes on
belief.

## Falsifiers
Q1's core fails if value is shown identical to desire/choice/reward with no possible
divergence (would collapse the spine — but reward hacking/akrasia are standing
counter-evidence). Q3 fails if a faithful utility exists for *every* value structure
including the provably incommensurable (would refute value ⊋ representable-value). Q5's
regress fails if a coherent value structure is exhibited with *no* terminal value and
no regress (all-instrumental yet grounded). The reward-as-sensor claim fails if reward
cannot, even in principle, misrepresent value (no possible hacking/wireheading).
