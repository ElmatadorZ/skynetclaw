## Primary question · What is a plan?

The traditions again answer "how," and philosophy of action answers "what":

- **OR / control / AI planning.** A plan is a sequence (or partial order) of actions
  transforming an initial state into a goal state, subject to resource and temporal
  constraints. — Defines a *well-formed* plan operationally; presupposes what a plan is.
- **Miller–Galanter–Pribram (*Plans and the Structure of Behavior*).** A plan is "any
  hierarchical process in the organism that can control the order in which a sequence of
  operations is to be performed." — Closer: a *control structure over ordered action*.
- **Bratman (planning agency).** A plan is a *partial, hierarchical, future-directed
  intention* that is (i) *stable* (resists reconsideration), (ii) *filter* on options,
  and (iii) demands *means-end coherence*. — The ontological core: a plan is an
  **elaborated commitment** — a commitment (Vol III) unfolded into a structured
  means-toward-end over time.

**Recovered core (SUPPORTED):** *a plan is a commitment elaborated into a
dependency-structured, resource-bound means toward a goal, held stable and open to
revision.* It is what a single Commitment (Vol III) becomes when it must be *realized
through many ordered, interdependent, world-consuming actions* rather than one. Planning
is the *activity* of producing and maintaining plans; a plan is its (revisable) product.

**Direction of fit.** A plan is **world→mind** throughout (it specifies how to *make* the
world match the goal), but — and this is the volume's pivot — its *field* has a physical
signature that inquiry's field lacks (file 01): acting **consumes and forecloses**, so a
plan must reason about an **irreversible, non-ergodic** world, whereas inquiry maps a
(largely) fixed, recurrent one.

## Objective 1 · The ontology (ten plan-entities), separated

Defined minimally, then *separated* from the ten look-alikes (Objective 4 does the full
matrix; here the entities themselves).

| Plan-entity | Minimal definition |
|---|---|
| **Plan** | a commitment elaborated into a dependency-structured, resource-bound means toward a goal |
| **Planning** | the activity of constructing / maintaining / revising plans |
| **Plan-state** | the current partial plan + its execution status (what is done, pending, blocked) |
| **Subgoal** | an intermediate state that must hold *en route* — a derived goal (Vol II Q6) serving a dependency |
| **Dependency** | a precondition relation: B requires A's effect before B is admissible |
| **Milestone** | a distinguished subgoal marking verifiable progress / a commit-point |
| **Constraint** | a limit on admissible plans (physical, normative, temporal) |
| **Resource** | a finite, *consumable* means whose expenditure by one action is unavailable to another |
| **Temporal order** | the (partial) ordering over actions — *induced*, per file 01, not primitive |
| **Revision** | the update of a plan under new observation (replanning) |

## Objective 4 · The boundary matrix — Plan vs the look-alikes

Each look-alike shares *something* with a plan and lacks *something*. The lacked feature
is the discriminating test.

| Not-a-plan (by itself) | Shares | **Lacks** (the discriminator) |
|---|---|---|
| **Goal** | the end | any *means-structure* — a goal is the target, a plan is the route (Vol II) |
| **Decision** | commitment | *temporal-dependency elaboration* — a decision is one committed choice; a plan is a committed *structure* of them (Vol III) |
| **Policy** | it guides action | *a specific committed path* — a policy is a *standing* state→action map for *all* states; a plan is a *particular* route for *this* situation (chess opening, animal migration are policies) |
| **Procedure / Recipe** | ordered dependent steps | *attachment to a particular goal-token now* — a procedure is a reusable *type*; a plan (token) is a procedure *committed to here* |
| **Prediction / Forecast** | future-directed | *commitment* — a forecast says what *will* happen (M→W, belief); a plan says what one *will make* happen (W→M) |
| **Explanation** | dependency structure | *future-direction + commitment* — an explanation is a backward dependency account of what *did* happen |
| **Algorithm** | ordered dependent operations | *commitment to a goal-in-a-world* — an algorithm is a goal-neutral computational schema; a plan is enacted in a consuming world |
| **Schedule / Calendar** | temporal order | ***dependency*** — a schedule is bare time-assignment with no precondition structure (the sharpest boundary; see file 04) |
| **Execution** | it realizes the goal | *the plan is not its execution* — a plan can exist unexecuted (like a belief unasserted); execution is its outward expression |
| **Wish / Checklist** | a set of desired ends | *dependency + commitment-to-means* — a checklist/shopping-list is an unordered goal-set, not a route |

**The two discriminators that do the most work (SUPPORTED, and they preview file 01):**
1. **Dependency** separates Plan from *Schedule/Checklist/Wish* — bare temporal order or
   a bare goal-set is not a plan; the precondition structure is what makes it one.
2. **Commitment** separates Plan from *Prediction/Explanation/Algorithm* — these have
   structure but no committed, goal-directed, world→mind stance. A forecast is the M→W
   twin of a plan: same future, opposite direction of fit.

Notice what is *not* in this list of discriminators: **Temporal order** does *not*
cleanly separate Plan from anything (a Schedule has it too). That is the first clue that
temporal order is not the load-bearing primitive the mission's formula made it — pursued
in file 01.

## Falsifiers
The core fails if a genuine plan is exhibited with no goal, no commitment, or no
dependency structure (a bare unordered goal-set that we would still call a plan — the
shopping list tests this and is judged *not* a plan). The direction-of-fit claim fails if
a genuine plan is really a prediction (M→W) rather than a prescription (W→M). The
boundary matrix fails if any discriminator column is shown non-discriminating (the
look-alike actually *is* a plan).
