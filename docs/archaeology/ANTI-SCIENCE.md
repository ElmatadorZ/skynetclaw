# Anti-Science — what the organism actively REJECTS (with evidence)

> A method is defined as much by what it refuses as by what it accepts. Each rejection is
> backed by an organ that structurally *blocks* the thing. Tags: SUPPORTED / LIKELY /
> SPECULATIVE / UNKNOWN. Rejections that evidence does NOT support are marked so — honestly.

## REJECTED-1 · Assertion / authority ("because I said so / TASK_COMPLETE") · SUPPORTED
completion-evidence: *"The House must PROVE completion, not merely assert it ... verifies the
claim against REAL evidence."* A run ending on the model *asserting* "TASK_COMPLETE" is
explicitly named as the failure this organ exists to stop. Authority-of-the-speaker carries
no weight; only checkable evidence does.

## REJECTED-2 · The single source / single experiment / single detector · SUPPORTED
- first-principles: *"corroborated by ≥ 2 independent systems ... so no single noisy detector
  can [promote it]."*
- reinforcement: *"no single mission can jump a weight more than MAX_STEP."*
- lesson-synthesis: *"A log is not a lesson ... only when REPEATED evidence ... produces a
  CONSISTENT [conclusion]."*
→ n = 1 can never establish belief. The strongest, most consistently-enforced rejection.

## REJECTED-3 · Correlation mistaken for causation · SUPPORTED
experiment: *"Move from CORRELATION ... to CONTROLLED VALIDATION — is X actually the CAUSE?
proposes controlled experiments — a control ordering vs a test ordering."* causal: *"turning
correlation into testable causal hypotheses."* Correlation is admitted only as a *hypothesis
to be tested*, never as cause.

## REJECTED-4 · Untestable / unfalsifiable claims · SUPPORTED
research-agenda ranks by *"how testable they are (leverage)"*; calibration can only grade a
belief that made a **checkable prediction**. A claim that predicts nothing observable cannot
be calibrated → cannot graduate past CANDIDATE. Untestability is a demotion, not a shelter.

## REJECTED-5 · Unsourced generated data (self-fabrication) · SUPPORTED
shadow-gate LIVE-DATA gate: a write asserting live reality (prices/dates/stats) is blocked
unless a **live tool sourced it**. The organism refuses to treat its *own* fluent output as
fact. (This is also OBJECTIVE-3's "refuses to believe itself.")

## REJECTED-6 · Overconfidence / confirmation bias · SUPPORTED
- calibration measures *its own* predicted-vs-observed gap → surfaces where "self-assessment
  can[not] be trusted."
- belief-revision actively hunts for *"RECENT evidence [that] contradicts a previously
  PROMOTED belief"* — a disconfirmation-seeking organ (the opposite of confirmation bias).
- the council **Skeptic** returns verdicts `CONSISTENT | FRAGILE | REBUILD` — institutionalised
  doubt with a veto path.
- unknowns keeps a standing ledger of *known-unknowns* and *unknown-unknowns*.

## REJECTED-7 · Storytelling / intuition — **as EVIDENCE** (but NOT as output) · LIKELY, with a caveat
As *evidence*, narrative is rejected: *"experience is not learning; a log is not a lesson."*
Belief must be quantified (support/confidence/lift/calibration), not narrated.
**Caveat (honesty):** storytelling is **not** rejected as *output* — a "Storyteller" persona
exists in both V1 and the current roster (Voice is an invariant, per ARCHITECTURAL_INVARIANTS).
So the rejection is precise: **narrative may not be evidence; it may still be voice.**

## NOT-CLEARLY-REJECTED · Majority opinion · UNKNOWN / partial
The classic scientific rejection of "truth by majority" is **not clearly supported**. The
organism runs a **council that deliberates and weighs positions**, and a Skeptic can veto —
which is *not* pure majority rule, but neither is it a documented rejection of consensus. No
organ was found that explicitly bars majority-as-truth. **UNKNOWN** — do not claim it.
