# Learned — SkynetClaw's own write area

> This folder is where **SkynetClaw itself** accrues durable discoveries via its Obsidian
> tools (`obsidian_write_note`), separate from the human-curated foundations. It is the
> narrative twin of [[Proprioception — Learning]] (which feeds the *prompt*; this is the
> *memory*).

## Rules (see [[How This Vault Grows]])
- The agent writes notes here when it discovers something **durable** — a resolved failure
  pattern, a confirmed operational fact, a working approach. Not chatter.
- Each note: what was learned · the evidence (a run id, a file, a measurement) · a
  `[[link]]` to the foundation it relates to.
- On review, a human **promotes** a proven `Learned/` note into the curated sections and
  links it from the relevant map.

## Convention
Filename: `YYYY-MM-DD - <short-slug>.md`. Tag `#learned`. Link liberally.
